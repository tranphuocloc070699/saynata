# Saynata

An iOS app for a Vietnamese English learner: look up words, translate sentences, hear them aloud,
and practise saying the meaning with a score.

| Folder | What |
|---|---|
| `EnglishTranslation/` | iOS app (SwiftUI) |
| `backend/` | Spring Boot API with a shared Postgres cache ([README](backend/README.md)) |
| `pipeline/` | Builds the bundled dictionary from NGSL + Wiktionary ([README](pipeline/README.md)) |
| `backlog/` | Tasks, spec and decisions ([Backlog.md](https://github.com/MrLesk/Backlog.md)) |

Spec: [backlog/docs/doc-1 - Vision-and-spec.md](backlog/docs/doc-1%20-%20Vision-and-spec.md).
