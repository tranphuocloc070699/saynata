## Lessons from this session
- Parallel workers duplicated types (WordEntry, normaliser); name shared models in the worker prompts.
- iOS tests are not in CI; the main chat runs them before merging iOS PRs.
- Never merge on a piped `gh pr checks` (the pipe hides failures); use `gh pr checks <n> --watch` and check its exit status.
- Disk filled up from worker build caches; remove merged worktrees and their DerivedData after merging.
- The developer's own simulator tests found what reviews missed (stale local branch, runk -> drunk, missing IPA, flicker).
